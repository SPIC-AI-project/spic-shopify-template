外部LP制作 ご依頼にあたってのルール

編集範囲について

HTMLファイル内に以下のコメントを記載しています。この範囲内のみを編集・追記してください。

<!-- ▼▼▼ LP記述ここから ▼▼▼ -->

（ここにLP用のHTML・CSS・JSを記述してください）

<!-- ▲▲▲ LP記述ここまで ▲▲▲ -->
範囲外のヘッダー・フッター・既存CSSは弊社サイトの共通パーツです。絶対に編集しないでください。

CSS記述ルール（重要）

弊社サイトのCSSと干渉しないよう、以下を必ず守ってください。

① すべてのスタイルを #dummy-lp-area 配下でスコープすること
/* NG */
h2 { font-size: 24px; }

/* OK */
#dummy-lp-area h2 { font-size: 24px; }
② 要素セレクタへの直接指定禁止

body a p h1〜h6 img など、タグ名への直接スタイル指定は禁止です。

③ !important の多用禁止

どうしても必要な場合のみ、理由をコメントで明記してください。

JS記述ルール

  • jQueryはすでに読み込み済みです。重複して読み込まないでください。
  • JSはページ下部（LP範囲内）にまとめて記述してください。
  • グローバル変数・既存関数の上書きは禁止です。

画像について

  • 画像ファイルはすべて、納品物の img フォルダ内に格納してください。
  • HTMLからの参照は img/ファイル名.webp の形式で記述してください。
    （弊社にてShopify登録後、URLを差し替えます）
ファイル命名規則
<公開時西暦><LP識別子>-lp-xxx.webp

例：ビタミンCのLPなら 2026vitc-lp-01.webp、2026vitc-lp-02.webp …

LP識別子は、そのLPのページURLに合わせて設定してください。（例：URLが vitamin-c-lp なら 2026vitc-lp-01.webp など）

PC/SPで画像を出し分ける場合は、末尾に -pc -sp を付与してください。

例：2026vitc-lp-01-pc.webp
    2026vitc-lp-01-sp.webp
使用可能な文字

ファイル名は半角英数字・ハイフン（-）・アンダースコア（_）のみで構成してください。

全角文字・半角スペース・@ # ! % などの記号は使用しないでください。

/* NG */
2026 vitc lp 01@2x.jpeg
画像 (1).png

/* OK */
2026vitc-lp-01.webp
2026vitc-lp-01_pc.webp
英字の大文字・連番の表記

英字はすべて半角小文字に統一してください。（Windows/Macで大文字・小文字の扱いが異なり、表示崩れの原因になります）

連番は2桁のゼロ埋め（01〜）で統一してください。

/* NG */
2026VitC-LP-1.webp

/* OK */
2026vitc-lp-01.webp
フォーマット

原則 WebP または SVG を使用してください。（軽量化にご協力ください）

NG：jpeg jpg png 形式での納品

納品物

  • HTMLファイル1本にすべて記述（インラインCSS・JS含む）
  • img フォルダ（画像一式）
  • 文字コード：UTF-8
